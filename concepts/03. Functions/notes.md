The order matters for variables and constants, whereas it does not matter for functions. These are able to be defined after they are called.

Two variables can be defined with the exact same name, as long as they are defined within different scopes (e.g. one is defined globally, while the other is defined within the scope of a function).

Functions can be exited early in conditional logic by simply calling the `return;` statement within them.

Leaving the parentheses away when calling a function means it is simply being referred to, instead of the code being parsed when the script is executed.
